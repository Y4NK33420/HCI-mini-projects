# Gesture Painting App

Creative painting application using hand gestures.

## Quick Start

Terminal 1 (Backend):
```bash
run_backend.bat
```

Terminal 2 (Frontend):
```bash
run_frontend.bat
```

## Gestures

- ☝️ Index Finger → Draw
- ✊ Fist → Erase
- ✌️ Peace Sign (1s) → Change Color
- ✋✋ Two Hands (2s) → Clear Canvas
- 🤏 Pinch → Adjust Size

## Requirements
- Python 3.10 or 3.11 (uses slide-gesture venv)
- Node.js
