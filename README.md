# HCI Mini Projects

Collection of gesture-based interaction applications using MediaPipe hand tracking.

## Projects

### 1. Aura - Gesture Presentation Control
Control presentations using hand gestures. Features two modes:
- **Mode 1**: Universal desktop controller (works with any presentation software)
- **Mode 2**: Web-based presentation viewer with gesture control

📁 Location: `slide-gesture/`

### 2. Gesture Painting
Creative painting application controlled entirely by hand gestures.

📁 Location: `gesture-painting/`

## Technology Stack

- **Backend**: Python, FastAPI, MediaPipe, OpenCV
- **Frontend**: React, TypeScript, Tailwind CSS
- **Hand Tracking**: Google MediaPipe

## Requirements

- Python 3.10 or 3.11
- Node.js 16+
- Webcam
